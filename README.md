# 🏆 League Standing Checker Bot

Real-time league standings aggregator for Telegram.

## Features
- 📊 Live standings from 8 top European leagues
- 🔄 Auto-updates every 30 minutes
- 📱 League selection
- 🏆 Champions League coverage
- No API keys required

## Commands
- `/start` - Welcome menu
- `/standings` - View live league standings
- `/leagues` - List all leagues
- `/select` - Choose a league
- `/refresh` - Force refresh
- `/subscribe` - Enable auto-updates
- `/unsubscribe` - Disable auto-updates
- `/help` - Help message

## Deploy on Railway
1. Fork this repo
2. Create Railway project
3. Add `BOT_TOKEN` environment variable
4. Deploy!
